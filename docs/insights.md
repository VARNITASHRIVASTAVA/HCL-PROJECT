# Insights Summary

All times are IST. Figures use valid videos only (2,071 videos).

## Key findings
1. Overall engagement: average ER is 2.607% and median ER is 1.956%.
2. Best day to post: Saturday has the highest average ER (3.044%); Monday has the lowest (2.396%).
3. Best hour to post: 1:00 IST has the highest average ER (3.773%).
4. Content types: Behind the Scenes / Vlog ranks first (6.199%) and Sports Highlights ranks last (1.659%).
5. Category comparison: Entertainment (2.894%) vs Sports (1.576%).
6. Effect of viral videos: average ER is 2.607% with outliers and 2.629% without them.

## Recommendation
Post Behind the Scenes / Vlog content on Saturdays around 1:00 IST to target the highest engagement.

## Limitations
- The data is YouTube trending videos, not all uploads, so results describe trending content.
- Content types come from keyword rules on titles, and 40.9% are "Other".
- Engagement rate is a ratio, so videos with very few views can have unusually high rates.
